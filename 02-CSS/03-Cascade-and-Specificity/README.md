# CSS Module 03 — Cascade, Specificity & Inheritance

This module focuses on understanding how CSS handles completing styles and how styles are inherited from parent elements.

The goal of this module is to understand **why a particular CSS rule wins** rather than simply writing CSS that works.

---

### Concepts Covered

* Cascade
* Inheritance
* Specificity
* Source Order
* `!important`

---

### Project — DevConnect

**DevConnect** is a developer community landing page created to practically apply CSS concepts learned in this module.

The project demonstrates how CSS behaves when multiple rules target the same elements, including:

* Inherited styles from parent elements
* Conflicting CSS declarations
* Selector Specificity 
* Equal-Specificity rules and Source order
* The effect of `!important`

The styling is intentionally limited to concepts learned so far. More advanced techniques will be introduced in later modules.


---

### Module Goal 

By completing this module, I should be able to : 

* Understand how the CSS cascade resolves conflicts
* Identify inherited and non-inherited properties
* Understand selector specificity
* Determine which selector has higher specificity
* Understand how source order affects competing rules
* Understanf the purpose and effect of `!important`
* Analyze why a particular CSS decalaration wins
