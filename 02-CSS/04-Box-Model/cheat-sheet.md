# CSS Module 04 — Box Model Cheat Sheet

### Box Model: `Content -> Padding -> Border -> Margin`

* **Content** -> Actual text/image/content
* **Padding** -> Space **inside** the box
* **Border** -> Box's boundary
* **Margin** -> Space **outside** the box

### Dimensions

*  `width` → Sets the width of an element.
* `height` → Sets the height of an element.
* `min-width` → Sets the minimum width of an element.
* `max-width` → Sets the maximum width of an element.
* `min-height` → Sets the minimum height of an element.
* `max-height` → Sets the maximum height of an element.

### Box-sizing

box-sizing: border-box

* `content-box` -> `width/height` = content only
* `border-box` -> `width/height` = includes **padding + border**

#### Remember

`padding = inside` | `margin = outside`

`border-box = predictable total size`
