# ☕ Aura Coffee — CSS Box Model Practice

A fictional specialty coffee landing page built to practice CSS Box Model concepts.

This project is part of my CSS learning journey, where I am implementing CSS concepts on a realistic website instead of practicing isolated examples.

## Project Overview

**Aura Coffee** is a fictional premium coffee brand website featuring:

* Hero Section
* Featured coffee products
* Why Aura section
* Brand story
* Coffee experiences
* Newsletter signup
* Contact information
* Footer

The HTML structure was created first, followed by CSS styling focused specifically on the **CSS Box Model.**

## Learning Goals

The main goal of this project is to understand and practically implement:

* Content
* Padding
* Border
* Margin
* Dimensions
* Box-sizing

Rather than simply memorizing these properties, I used them throughout the website to understand how they affect the size, spacing, and layout of elements.


## CSS Box Model Concepts Practiced

### Content

The actual content inside an element such as: 

* Text
* Images
* Headings
* Buttons

### Padding

Used to create space **inside** elements between the content and border.

Examples: 

* Header spacing 
* Product card spacing
* Form input spacing
* Section spacing

### Border

Used to create visible boundaries around elements.

Examples:

* Product cards
* Feature cards
* Header bottom border
* Footer top border
* Form input

### Margin

Used to create space **outside** an element.

Examples:

* Space between cards
* Space between paragraphs
* Space between contact information
* Space around experience cards

### Dimensions

Practiced:

* width
* height
* min-height
* max-width

These were applied to sections, cards, images, text containers, and form elements.

### Box-sizing

Practiced:

box-sizing: border-box;

This was mainly applied to cards and form elements to understand how padding and borders affect the final dimensions of an element.
