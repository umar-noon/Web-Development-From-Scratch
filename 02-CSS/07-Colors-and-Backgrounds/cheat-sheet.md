# CSS Module 07 — Colors & Backgrounds Cheat Sheet

## Colors

- **HEX:** Hexadecimal color value.  
  `#FF0000`

- **RGB:** Red, Green, Blue color model.  
  `rgb(255, 0, 0)`

- **RGBA:** RGB with transparency (alpha).  
  `rgba(255, 0, 0, 0.5)`

- **HSL:** Hue, Saturation, Lightness.  
  `hsl(0, 100%, 50%)`

- **Opacity:** Controls element transparency.  
  `opacity: 0.5;`

---

## Gradients

- **Linear Gradient:** Colors transition in a straight direction.  
  `linear-gradient(to right, red, blue)`

- **Radial Gradient:** Colors transition outward from a center point.  
  `radial-gradient(circle, red, blue)`

---

## Backgrounds

- **background-color:** Sets background color.  
  `background-color: #fff;`

- **background-image:** Adds an image or gradient as background.  
  `background-image: url("image.jpg");`

- **background-position:** Sets background image position.  
  `background-position: center;`

- **background-size:** Controls background image size.  
  `background-size: cover;`

- **background-repeat:** Controls image repetition.  
  `background-repeat: no-repeat;`

---

## Key Difference

- **RGBA Alpha:** Makes only the color transparent.
- **opacity:** Makes the entire element and its content transparent.
