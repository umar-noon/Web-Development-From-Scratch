# CSS Module 07 — Colors & Backgrounds

A CSS practice project focused on applying colors, gradients, opacity, and background techniques to a creative studio website.

## Live Demo

[View Live Project](https://lumen-creative-studio.netlify.app/)

---

## Concepts Practiced

### Colors

- HEX Colors
- RGB Colors
- RGBA Colors
- HSL Colors
- Opacity

### Backgrounds

- Background Colors
- Linear Gradients
- Radial Gradients
- Background Images
- Background Position
- Background Size
- Background Repeat

---

## Color Palette

A cohesive and classic color palette was used throughout the project:

- **Cream**
- **Off White**
- **Charcoal**
- **Terracotta**
- **Soft Beige**

The palette was chosen to create a clean, warm, and professional creative studio aesthetic.

---

## Background Techniques

The project demonstrates multiple background techniques, including:

- Gradient overlays on background images
- Linear gradients for section backgrounds
- Radial gradients
- Background image positioning
- `background-size: cover`
- `background-repeat: no-repeat`
