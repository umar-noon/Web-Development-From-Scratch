# Gadget Grove — CSS Fundamentals

A simple tech store webpage built as part of my **Web Development From Scratch learning journey.**

This project focuses on practicing and demonstrating fundamental **CSS selectors, pseudo-classes, pseudo-elements, specificity, cascade, and reusable class naming**.

The HTML structure was kept relatively simple so the main focus could remain on CSS.

---

### Project Overview

**Gadget Grove** is an online tech store featuring products such as laptops, smartphones, and headphones.

The project was created to apply CSS concepts learned in **CSS Module 02 — CSS Fundamentals** to a practical webpage.

The design is intentionally simple because the primary goal of this project is **CSS practice rather than visual design**.

## Learning Objective

The main objective of this project was to understand how CSS selectors target HTML elements and how different CSS rules interact through **specificity, cascade, and source order**.

Instead of only studying selectors theoretically, I applied them to a single practical webpage to understand their behavior in a real HTML structure.
