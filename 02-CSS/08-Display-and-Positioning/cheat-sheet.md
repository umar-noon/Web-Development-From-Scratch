# CSS Module 08 — Cheat Sheet

## Display

### `block`
Takes full available width and starts on a new line.

### `inline`
Stays in the same line and only takes content width.

### `inline-block`
Stays inline but allows width, height, padding, and margin.

### `none`
Completely hides an element and removes its space.


## Positioning

### `static`
Default position. Follows normal document flow.

### `relative`
Stays in normal flow but can be positioned relative to itself.

### `absolute`
Removed from normal flow and positioned relative to its nearest positioned ancestor.

### `fixed`
Positioned relative to the viewport and stays while scrolling.

### `sticky`
Behaves normally until a scroll position, then sticks to a specified position.

---

## `z-index`

Controls which positioned element appears on top when elements overlap.

Higher `z-index` = appears above lower `z-index`.
