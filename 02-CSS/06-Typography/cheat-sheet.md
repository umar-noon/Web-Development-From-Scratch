# CSS Typography Cheat Sheet

### `font-family` 

Sets the typeface of text.

### `font-size`

Control the size of text.

### `font-weight`

Controls how thin or bold text appears.

### `line-height`

Controls the space between lines of text.

### `letter-spacing`

Controls the space between space of letters.

### `word-spacing`

Controls the space between words.

### `text-decoration`

Adds or removes decorations like underline.

### Web Fonts

External Fonts loaded from services like Google Fonts.
