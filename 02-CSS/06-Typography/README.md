# LUMEN — Creative Studio

A typography-focused creative studio website built to practice and implement core CSS **Typography** concepts.

### About

LUMEN is a static creative studio webpage designed with a strong focus on **typography, readability, text hierarchy, and web fonts**

The project uses a combination of elegant serif headings and clean sans-serif body text to create a professional and visually structured reading experience.

### Concepts Practiced

* Font Family 
* Web Fonts
* Font Size
* Font Weight
* Line Height
* Letter Spacing 
* Word Spacing
* Text Decoration

### Typography

Headings: Playfair Design 
Body Text: Inter

### Technologies Used

* HTML5
* CSS3
* Google Fonts
