# Web Development From Scratch

**Learning web development from the ground up -- one concept, one challenge, and one project at a time.**



This repository contains my complete **Web Development From Scratch** journey.



The goal is not simply to learn how to build websites, but to develop a strong understanding of **how the web works, how websites are structured, styled, made interactive, and eventually connected to back-end systems and databases.**



Everything in this repository is organized according to my learning progression, from fundamental concepts to more advanced development.



### Goal



My goal is to build a strong foundation in web development by learning: 



* HTML
* CSS
* JavaScript
* Responsive Web Design
* Git \& GitHub
* Front-End Development
* Back-End Development 
* Databases
* APIs
* Full-Stack Development



Along the way, I will document my learning through notes, exercises, challenges, experiments, and projects.
