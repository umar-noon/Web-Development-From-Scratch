### HTML Fundamentals - Medicare Hospital



A multi-page hospital website built using pure HTML to practice and demonstrate core HTML fundamentals.



This project was created as part of my Web Development From Scratch learning journey, with a focus on writing structured, semantic, accessible, and organized HTML.



#### Project Overview



Medicare Hospital is a fictional multi-page healthcare website that allows users to explore hospital information, view doctors and services, and register for an appointment.



The project focuses entirely on --HTML structure and functionality--. No CSS or JavaScript is used at this stage.
